# Como contribuir

Para adicionar um novo exercício, coloque o arquivo na pasta do capítulo correspondente e use o padrão `questao-XX.c` ou `questao-XX-letra-a.c`.

Compile o projeto com `make` antes de abrir um pull request. O código deve compilar sem erros e, sempre que possível, sem avisos com `-Wall -Wextra -Wpedantic`.
